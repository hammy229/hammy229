# Arham Doshi

CS + Linguistics @ UT Austin · ML/NLP Research · Uncertainty in LLMs

## About

I work on measuring and modeling uncertainty in language — how it shows up in text, how humans express it, and how language models represent (or fail to represent) it. My current research focuses on training models to better handle that uncertainty rather than treating it as noise.
